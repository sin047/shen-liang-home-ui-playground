# Glass System 4.2.2 — Continuous Optics

状态：**独立视觉试验，待 iPhone Safari 真机验收**。

## 来源与已知事实

- 用户已在 iPhone 上验证 4.2.1 页面显示 `GPU · fwidth AA`，`DPR 3.00`、`MSAA on`；截图中使用了樱花背景，并将折射强度调至约 `0.74`、内侧厚度调至 `1.00`。
- 用户之前确认圆角形状可以保留、清透度值得保留；尚未认可现有版本达到了其参考 `yanceydaisy/liquid-glass-note` 的 CLEAR 材质观感。
- 基于图像观察，前版中外侧的折射有局部水波或鼓包感，光照体积感也仍然较弱；这是视觉判断，不是测量到的物理光学误差。
- 参考仓库提供的公开技术与图片仅作视觉方向。**本版为独立编写，未复制其未授权的生产 Shader、界面或资源。**

## 本轮工作目标

在保留圆角、背景清透度、DOM 文字、相册上传与 GL 共享纹理实现的基础上：

1. **让整个玻璃面成为一张连续透镜**：降低局部肩部峰值，尤其降低中外侧被压缩得太厉害的变形。
2. **让光学厚度主要由独立曲面反光承担**：不是再往背景折射里叠加局部水波。
3. **保持轮廓细、透射清晰**：不加入奶白底色、整圈白描边、长时间 GPU 动画或额外纹理资产。

## 4.2.2 与 4.2.1 的具体差异

### 连续透镜轮廓

4.2.1 由单一 `lensBody` 与中外段 `shoulderWindow` 叠加，因此曲率/位移可能在中外段形成第二个局部峰值。

4.2.2 删除独立的 shoulder 项及局部切向波段，改用：

```glsl
float dome=max(1.0-r*r,0.0);
float opticalProfile=dome*(0.93+0.10*dome);
vec2 displacement=p*opticalProfile*(96.0*power);
```

该径向位移在中心 `r=0`、轮廓 `r=1` 为零，绝对位移沿半径只有一个峰值。保留很弱的静态 `sin/cos` 微扰，并乘 `dome*dome` 让其在轮廓处趋于零。不会绘制连续动画。

### 光感与厚度

- 延续同一圆角 SDF 蒙版、局部边缘法线与自适应亮度计算。
- 轻微调整 `bevel` 和 `shoulderShade` 的衰减宽度：让内侧暗部更连续。
- 保留两个方向性外缘高光，但降低细线占比；避免形成整圈白边。
- 从模拟三维曲面法线导出局部反光 `areaLobe`，再与一条很淡、具有空间范围的斜向 `lightRibbon` 组合。两者都受 `reflectionEnvelope` 限制，不以整块奶白透明层代替反射。
- 保留 CLEAR/SMOKED 模式与原本的非彩色透射；不改阴影、边框形状、文字、控件位置。

### 数值验证

折射强度取用户截图的 `power=0.74`，只计算主透镜径向位移，不计叠加的微弱低频扰动：

| 半径 r | 4.2.1 位移（屏幕纹理像素） | 4.2.2 位移（屏幕纹理像素） |
| --- | ---: | ---: |
| 0.25 | 17.07 | 17.05 |
| 0.50 | 27.07 | 26.77 |
| 0.70 | 34.44 | 24.88 |
| 0.80 | 32.83 | 19.76 |
| 0.90 | 27.45 | 11.53 |
| 0.99 | 3.85 | 1.30 |
| 1.00 | 2.54 | 0.00 |

在 `r≈0.565`，4.2.2 主透镜峰值约 `27.27` 像素；4.2.1 的峰值约 `34.71` 像素。新分布为单峰，并在真实边界归零。数值检查不能证明视觉更好，也未包含低频扰动对最终位移的影响。

## 验证方式

**已做源码检查**：JavaScript 可解析、主透镜数学轮廓与单峰性抽查、原始圆角 SDF 与蒙版的保留、两个 GPU Shader 源码变体的未声明变量检测、模式与生命周期代码存在性检查。

**尚待设备验证**：
1. iPhone Safari 首次加载显示 `GPU · fwidth AA`，而不是 `CSS fallback`。
2. 使用同一樱花照片与相同的四个滑块数值，对比 4.2.1 与 4.2.2，尤其观察桥梁/枝条在长气泡边缘是否减少扭曲波纹。
3. 点击 `原图对照` 验证真实折射，而不是误将背景自身变化当玻璃。
4. 看上缘与两端的局部反光是否更有空间层次、有没有出现斜向亮斑、白壳或灰壳。
5. 测试 CLEAR / SMOKED、缩放、横竖屏、切后台和更换背景。
6. 只有用户明确认可视觉，才考虑后续样式定版或正式产品集成。

**不夸大验证**：本次没有 iPhone Safari GPU 实测，也没有测量 GPU 帧时间或内存。静态标识符检查并非完整 GLSL 编译；如部署后出现 Shader 错误，以页面显示的错误信息为准。
