# Glass System 3.0 — 移动端验证清单

本清单对应 P1 移动端稳定性阶段。请在 iPhone Safari 中验证；视觉参数和玻璃外观在本轮没有调整。

## A. 首次加载

- [x] 页面能正常打开，四个气泡均显示。
- [x] 状态栏显示 `WebGL · DPR 3.00 · fwidth AA · MSAA on`（本次 iPhone Safari 实测）。
- [x] 默认渐变背景下，气泡轮廓、折射和文字均正常。
- [x] 页面没有持续闪烁或黑块；用户未报告初始化异常。

## B. 自定义背景

- [x] 从相册选择一张图片，背景与气泡内折射同步更新。
- [x] 再次选择同一张图片，仍能触发更新。
- [x] 连续更换两张不同图片，最终背景与折射采样保持一致。
- [x] 图片加载失败降级逻辑已通过代码检查；未单独注入损坏图片进行设备测试。

## C. 视口与滚动

- [x] 页面上下滚动时，折射区域始终与气泡位置对齐。
- [x] 双指放大、缩小后，轮廓和折射仍保持对齐。
- [x] 横竖屏切换或浏览器视口尺寸变化后，画面能重新适配。
- [x] 页面滚动到气泡部分离开屏幕，再返回时，渲染正常。

## D. 后台恢复

- [x] 切换到其他 App，再返回 Safari，玻璃效果仍正常。
- [x] 锁屏后重新打开，画面能恢复，不需要手动刷新。

## E. 降级与恢复（可选，需要浏览器调试能力）

- [ ] 模拟 WebGL Context Lost 后，气泡切换为 CSS fallback，而不是消失。
- [ ] Context 恢复后，WebGL 重新初始化，原背景与气泡折射恢复。
- [ ] 在不支持 WebGL 的环境中，页面仍显示可读的轻量 CSS 玻璃气泡。

## 反馈时请提供

如果某一步失败，尽量提供：
1. 失败步骤编号；
2. 页面状态栏显示的完整文字；
3. 截图或录屏；
4. 是否发生在更换背景、缩放、滚动或切后台之后。
