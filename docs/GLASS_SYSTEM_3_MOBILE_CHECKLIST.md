# Glass System 3.0 — 移动端验证清单

本清单对应 P1 移动端稳定性阶段。请在 iPhone Safari 中验证；视觉参数和玻璃外观在本轮没有调整。

## A. 首次加载

- [ ] 页面能正常打开，四个气泡均显示。
- [ ] 状态栏显示 `WebGL · DPR ... · fwidth AA · MSAA ...`（具体 DPR 和 MSAA 值因设备而异）。
- [ ] 默认渐变背景下，气泡轮廓、折射和文字均正常。
- [ ] 页面没有持续闪烁、黑块或控制台可见的初始化错误。

## B. 自定义背景

- [ ] 从相册选择一张图片，背景与气泡内折射同步更新。
- [ ] 再次选择同一张图片，仍能触发更新。
- [ ] 连续更换两张不同图片，最终背景与折射采样保持一致。
- [ ] 图片加载失败时，页面仍可继续使用，不出现空白气泡。

## C. 视口与滚动

- [ ] 页面上下滚动时，折射区域始终与气泡位置对齐。
- [ ] 双指放大、缩小后，轮廓和折射仍保持对齐。
- [ ] 横竖屏切换或浏览器视口尺寸变化后，画面能重新适配。
- [ ] 页面滚动到气泡部分离开屏幕，再返回时，渲染正常。

## D. 后台恢复

- [ ] 切换到其他 App，再返回 Safari，玻璃效果仍正常。
- [ ] 锁屏后重新打开，画面能恢复，不需要手动刷新。

## E. 降级与恢复（可选，需要浏览器调试能力）

- [ ] 模拟 WebGL Context Lost 后，气泡切换为 CSS fallback，而不是消失。
- [ ] Context 恢复后，WebGL 重新初始化，原背景与气泡折射恢复。
- [ ] 在不支持 WebGL 的环境中，页面仍显示可读的轻量 CSS 玻璃气泡。

## 反馈时请提供

如果某一步失败，尽量提供：
1. 失败步骤编号；
2. 页面状态栏显示的完整文字；
3. 截图或录屏；
4. 是否发生在更换背景、缩放、滚动或切后台之后。

这份清单是设备端验证，不代表当前已经通过。静态代码检查不能替代真实 iPhone Safari 测试。
