# Glass System 4.1 — CLEAR 材质修正与 GPU 诊断

状态：**待设备验收**。本版在独立 Playground 的新页面 `docs/glass-system-41.html`，不覆盖原 `glass-system-40.html` / `glass-system-30.html`，也不改动正式产品仓库。

参考视觉方向：`https://github.com/yanceydaisy/liquid-glass-note` 的 CLEAR 示例（参考项目公开的是技术文档、截图与节选，不是获授权的可复制完整引擎）。本版 GLSL 为独立实现，未包含其生产 Shader 或图像资产。

## 来自用户的实际反馈

用户在 iPhone Safari 使用樱花/街景图测试 4.0，观察到：
- 圆角与气泡外形可以接受。
- 气泡内部看起来像均匀的浅粉、浅白半透明卡片。
- 没有明显的整块玻璃折射、表面亮暗变化与真实厚度感。

**尚未证实的假设：** 截图里的均匀填充与白边也符合 `.stage.css-fallback .message` 的降级样式。4.0 在 WebGL 初始化失败时隐藏真实 Canvas，但此前仅把错误写在卡片下方状态栏，截图无法证明 GPU Shader 是否启动。本轮必须优先消除这个诊断盲点；不能简单认定是折射参数太低。

## 本轮按源头分离的修改

### 1. GPU / CSS fallback 可见诊断
- 在聊天背景内部右下角增加小型状态标识：`GPU · fwidth AA` 或 `CSS fallback · …`。
- Shader 编译／链接失败会把简短原因写到原状态文字和标识的 `title`，控制台保留异常。
- 初始化、背景上传、实际绘制、上下文丢失／恢复等路径均保留失败标识，不再让纯 CSS 降级被误判为玻璃引擎效果。
- 将旧 GLSL 中可能与较新 GLSL 关键词冲突的 `flat` 局部变量改成 `straightRegion`；本轮依然需要真实 Safari 验证能否编译。

### 2. 全表面折射修正
- 使用一套圆角 SDF 和圆角射线交点得到归一化位置，保持外形与折射场一致。
- 用连续的径向透镜曲率主导背景重采样：默认折射从 0.46 调整为 0.61，透镜强度表达式独立修改；中央和中层不再退化为纯边缘环。
- 使用静态低频扰动（默认 0.12），无持续动画。
- `原图对照` 按钮可以临时旁路所有折射、边缘明暗与高光，直接展示 GPU 里的原始纹理：用同一背景、同一布局比较差异，比通过主观感觉猜测参数更可靠。

### 3. 透明度与层次
- 默认 CLEAR 不添加任何覆盖整个表面的统一白色／粉色填充。
- 用背景亮度决定极细轮廓的明暗；不绘制第二圈白色 CSS 边框。
- 用方向性局部反光、轻微内侧吸光与原有两层柔软投影建立厚度，避免均匀奶白板。
- SMOKED 保留为独立中性吸光预设，不影响 CLEAR 的清透配方。
- 玻璃背景来自既有共享 WebGL 背景纹理与居中 `cover` 裁切；原有图片上传、预算、滚动更新、`gl.scissor`、上下文处理全部保留。

### 4. 不变的边界
- 不修改聊天布局、文字、圆角 25 CSS px、背景上传流程或原 4.0 页面。
- 不移植参考仓库未授权的代码、生产素材或私人 UI。
- 只加入独立 HTML、测试记录和 README 指针。
- 不把用户喜欢的当前圆角视作材质已验收。

## 源码与数学检查

- JavaScript 可解析。
- Shader 不再使用 `flat` 标识符，使用 `roundedRayLength` 与同一套 `roundedDistance` 几何。
- 对不同气泡尺寸以 2001 个方向采样核对射线终点与圆角 SDF，最大绝对误差约 `9.3e-13` 像素（纯数学检查，不是 GPU 渲染证明）。
- 新 Shader 不含全局白色填充；有明确的原图旁路分支和方向性局部高光。
- CSS fallback、WebGL 恢复、背景纹理限制、滑块控制和 scissor 路径通过源码存在性检查。

## iPhone Safari 的最小验收路径

1. **先看画面右下角状态。** 只有看到 `GPU · …` 才可以评估 Shader 的玻璃质感。若看到 `CSS fallback`，请截图该状态和下方详细状态；暂停调参，先修兼容。
2. 使用同一张樱花图，比较 4.0 / 4.1；主要观察枝条、伞骨和建筑窗框在气泡内是否出现连贯位移。
3. 在 4.1 中来回切换 `原图对照` / `恢复玻璃`；应能明确看到背景图案的变形，而不是只有边缘的白色线条在变化。
4. 把折射强度调到 0 再调到默认值和较高值，检查中间/边缘变形是否连续、没有边界跳变。
5. 亮背景 CLEAR 和深背景 CLEAR 分别检查，没有奶白填充、整圈白光或灰色厚壳。
6. 切换 SMOKED、滚动、缩放、横竖屏、相册换图和后台恢复；不出现丢纹理或圆角错位。

**状态说明：** 本轮完成的是独立代码实施、JavaScript 静态检查与圆角射线数值检查；真实 iPhone Safari 上的 Shader 编译、WebGL 连续渲染与最终外观尚未经验证。不声称与参考截图已达到像素级一致。
